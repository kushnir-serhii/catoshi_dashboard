## spec: extra rules

- When the spec file is created, create `decisions.md` next to it and log every question, answer and `[NEEDS CLARIFICATION]` resolution there (step tag `spec`).
- Record in `decisions.md` any user answer that already implies a technical choice (e.g. "use the existing chart", "same modal as settings") as `- [spec] TECH-HINT: …`. `/awos:tech` will use these instead of asking again.
